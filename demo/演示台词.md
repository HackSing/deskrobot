# 演示台词（约 3 分钟）

准备：看板“会前准备”里建好项目“供应商报价”，议程两条（各 1 分钟，方便演示超时），参会人张三、李四、王五，上传 `演示资料_供应商对比表.md`。运行 `python demo/seed.py` 预置一条上次的待办。

1. 张三：主持人，开始供应商报价的会议。 → 机器人播报上次遗留待办
2. 李四：B 家最便宜，但起订量要五千。王五：吃不下。张三：主持人，记下这个重点：B 家因起订量排除。 → 点头
3. 李四：主持人，资料里 A 家和 C 家的交期分别是多少？ → 从资料回答
4. 王五：C 家那颗芯片是不是停产了？李四：主持人，查一下。 → 思考，联网回答
5. 王五：中午吃什么？李四：楼下新开了家粉。（持续半分钟以上） → 无语表情，再开口
6. 等到超时 → 底灯红闪，提醒
7. 张三：那就定了，李四，周五前拿到 A 家的正式报价。主持人，会议结束。 → 复述待办，李四拍背

备份：语音不灵就在看板底部输入框里打同样的字。
