# H5 接口与字段说明

给前端 H5 用。后端在 `web/server.py`，由大脑维护。这份文档是大脑和 H5 之间的唯一契约，改字段先改文档。

先做 MVP：只保留必需字段和四个接口的精简版见 `docs/H5对接方案_MVP.md`，本文档是完整版，MVP 跑通后再按这里扩。

约定：所有接口返回 JSON；出错返回 4xx 和 `{"error": "原因"}`；时间戳都是 Unix 秒；标"待加"的字段大脑侧还没实现，H5 按可选字段处理，没有就当空。

## 1. 实时快照

WebSocket `/ws`：连上先收一条完整快照，之后状态一变就再收一条完整快照，不是增量。`GET /api/state` 返回同样的东西，刷新页面时用。

| 字段 | 类型 | 说明 | 状态 |
| --- | --- | --- | --- |
| `state` | string | 状态机状态：`idle` 空闲、`meeting` 会中、`confirming` 逐条确认待办 | 已有 |
| `robot_name` | string | 机器人名字，如"小登" | 已有 |
| `meeting_id` | string | 本场会议 ID，未开始为空字符串 | 已有 |
| `project` | string 或 null | 项目名 | 已有 |
| `agenda` | AgendaItem[] | 议程 | 已有 |
| `current_item` | int | 当前议题在 agenda 里的下标 | 已有 |
| `elapsed` | int | 已用秒数 | 已有 |
| `total` | int | 总秒数，未开始为 0 | 已有 |
| `materials` | string[] | 资料文件名 | 已有 |
| `transcript` | Utterance[] | 最近 50 句转写 | 已有 |
| `marks` | string[] | 已记重点 | 已有 |
| `last_answer` | Answer 或 null | 最近一次问答 | 已有 |
| `last_said` | string | 机器人刚说的话 | 已有 |
| `minutes` | Minutes 或 null | 散会后出现 | 已有 |
| `cue` | string | 机器人当前反馈名，如 `thinking`、`speaking`、`idle`，用来显示"思考中" | 待加 |
| `confirming_index` | int 或 null | 确认阶段正在确认第几条待办，其他时候 null | 待加 |
| `session` | Session 或 null | 房间信息 | 待加 |
| `server_ts` | float | 服务器时间，用来校准倒计时 | 待加 |

嵌套类型：

| 类型 | 字段 |
| --- | --- |
| AgendaItem | `title` string，`minutes` float |
| Utterance | `text` string，`ts` float |
| Answer | `question` string，`text` string，`source` string，`sources` Source[] 待加 |
| Source | `kind` string，`label` string，`ref` string，例如 kind 为 materials、label 为"会议资料"、ref 为"供应商对比表.pdf 第 3 页" |
| Minutes | `conclusions` string[]，`todos` Todo[]，`open_questions` string[]，`highlights` string[] |
| Todo | `id` int 或 null，`project` string，`owner` string，`content` string，`due` string，`status` string 取 open 或 done，`confirmed` bool，`meeting_id` string |
| Session | `status` string，`session_id` string，`project` string，`join_url` string，`participants` string[] 发起表单里填的参会人，`joined` Joined[] |
| Joined | `name` string，`joined_at` float |

`source` 和 `Source.kind` 的取值与中文标签：

| 值 | 标签 |
| --- | --- |
| `materials` | 会议资料 |
| `transcript` | 本场转写 |
| `history` | 历史纪要 |
| `web` | 联网 |
| `none` | 没找到 |

`session.status` 的取值：`none` 没有房间、`open` 已发起可扫码、`in_meeting` 会中、`ended` 已结束。

页面视图由 `session.status` 和 `state` 共同决定：

| `session.status` | `state` | 发起人 | 参与人 |
| --- | --- | --- | --- |
| none | idle | 发起表单 | "会议还没发起" |
| open | idle | 二维码、名单、上传、开始按钮 | 加入页，加入后等待页 |
| in_meeting | meeting | 会中看板 | 会中看板 |
| in_meeting | confirming | 会中看板，高亮 `confirming_index` 那条待办 | 同左 |
| ended | idle | 纪要页 | 纪要页，`owner` 等于自己名字的待办高亮 |

## 2. 房间接口，待加

发起人身份用请求头 `X-Host-Token` 传发起人令牌。参与人身份用加入时返回的 `client_id`，存在浏览器本地。

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| POST | `/api/session` | `project` string，`agenda` AgendaItem[]，`participants` string[]，`background` string | `session_id`，`host_token`，`join_token`，`join_url`。已有未结束房间返回 409 |
| GET | `/api/session` | 无 | Session，没有房间时 `status` 为 none |
| POST | `/api/session/join` | `token` string 来自 URL 参数 t，`name` string | `client_id`，`name`。房间不在 open 或 in_meeting 或令牌不对返回 403 |
| POST | `/api/session/materials` | multipart 字段 `file`，请求头带发起人令牌 | `ok`，`filename`，`chars`。不支持的类型返回 400 |
| POST | `/api/session/start` | 请求头带发起人令牌 | `ok`。房间不是 open 返回 409 |
| POST | `/api/session/close` | 请求头带发起人令牌 | `ok`。作废房间，用于演示重来 |

`join_url` 形如 `http://局域网IP:端口/h5?t=加入令牌`，后端把 `/h5` 映射到 `web/static/h5.html`，前端从 URL 参数 t 取令牌。

## 3. 现有接口

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/state` | 无 | 快照，同 WebSocket |
| GET | `/api/preps` | 无 | string[] 已保存的项目名 |
| GET | `/api/prep/{project}` | 无 | `project`，`agenda`，`participants`，`background`，`materials` Material[]。没有返回 404 |
| POST | `/api/prep` | `project`，`agenda`，`participants`，`background` | `ok` |
| POST | `/api/materials/{project}` | multipart 字段 `file` | `ok`，`filename`，`chars`。先保存准备再上传，否则 400 |
| GET | `/api/minutes/latest` | 无 | `meeting_id`，`project`，加 Minutes 的四个字段；没有时返回空对象 |
| GET | `/api/todos/{project}` | 无 | Todo[] 该项目未完成的待办 |
| POST | `/api/todos/{id}/done` | 无 | `ok` |
| POST | `/api/debug/say` | `text` string | `ok`。模拟有人说了一句话，演示保底用 |
| POST | `/api/debug/touch` | 无 | `ok`。模拟拍背 |

Material 的字段：`filename` string，`text` string。`text` 可能很长，H5 只显示文件名。

发起人流程用第 2 节的房间接口，不再直接调 `/api/prep` 和 `/api/materials`，那两个留给桌面页和调试。

## 4. 前端本地存储约定

存在 localStorage，键名统一，方便刷新后恢复身份：

| 键 | 值 |
| --- | --- |
| `role` | `host` 或 `guest` |
| `host_token` | 发起人令牌 |
| `client_id` | 参与人 ID |
| `name` | 参与人选的名字 |
| `session_id` | 加入时的房间 ID，与当前房间不一致就清掉重新加入 |
