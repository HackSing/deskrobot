## 3. 怎么跑

启动后端，终端会打印看板地址、H5 地址、推送状态：

```bash
python run_local.py
```

不用机器人、不用对方前端就能自测一遍，约一分钟：

```bash
python demo/e2e_demo.py
```

跑单元测试：

```bash
python -m pytest -q
```

改了前端要重新构建，产物在 `web/static/h5/`，随源码一起提交：

```bash
cd web/h5 && npm install && npm run build
```

手工驱动：桌面看板底部调试框，或手机 H5 加 `?debug=1`，依次输入"小登，开始会议"、"小登，资料里 A 家和 C 家的交期分别是多少"、"小登，那 B 家呢"、"小登，会议结束"。

## 4. 前端联调

已接通，接法是拉取：页面连我们的 `/ws`，断了轮询 `/api/state`。范围只有一个：`state` 回到 `idle` 且 `minutes` 非空时，页面切到会后页显示纪要。会前、会中页面仍是前端自己的演示数据，不联动。

1. `python run_local.py`，手机开终端打印的 `H5：http://<IP>:8766/h5`，页脚应显示"已连接机器人后端"。
2. 说"小登，开始会议"，再说"小登，会议结束"（或 `/api/debug/say` 发这两句），约 8 秒后手机应切到会后页，显示 3 条结论、3 条待办、2 条未决。
3. 字段对不上改 `web/h5/src/utils/backend.js` 和 `App.jsx` 的 `applyMinutes`，然后 `npm run build`。`core/push.py` 的 HTTP 推送这版前端用不上，`H5_PUSH_URL` 留空。
4. 手机打不开我们的地址，先查三件事：是否同一个 Wi-Fi；Windows 防火墙是否放行 8766 入站；终端打印的 IP 是否是真实网卡而不是虚拟网卡。本机曾打印过 198.18.0.1 这种虚拟地址，遇到就改用 `ipconfig` 里无线网卡的 IPv4。

## 6. 关键决定和原因

- **不用智能体框架。** 问答是一个带对话历史的单次调用加 JSON 解析，没有工具循环，框架只会增加延迟和打包风险。
- **`.env` 优先于系统环境变量。** 本机用户级环境变量里有别的项目留下的 `LLM_MODEL=deepseek-ai/DeepSeek-V3.2`，原来的 setdefault 会被它盖掉，每个问题都答"没找到"。
- **deepseek-flash 必须关思考。** 不关的话推理内容把 max_tokens 吃光，正文返回空串。通过 `LLM_EXTRA={"thinking":{"type":"disabled"},"max_tokens":400}` 并进每次请求体。
- **JSON 模式下对话历史里的 assistant 内容存 JSON 原文。** 存纯文本时 DeepSeek 只回空白，追问必挂。解析出空文本还会去掉 JSON 模式重问一次。
- **LLM 看到的是完整 mock 记录，不是灌了多少。** 提问不受灌入进度限制，任何时候问都行。灌入只是让看板动起来。
- **推送为主，拉取保底。** 对方自建页面接推送最省事；`/ws` 和 `h5.html` 留着，对方没做完也能演。
