# 会议主持机器人 Meeting Host

一个基于 React 的会议主持机器人前端原型，用于智能会议记录、实时问答和待办事项管理。

## ✨ 新增功能

### 1. 💾 数据持久化
- **自动保存**：会议进行中自动保存所有数据到本地存储
- **断点恢复**：刷新页面后可以继续上次的会议
- **数据清除**：支持手动清除所有保存的数据

### 2. 📤 导出功能
- **Markdown 导出**：生成格式化的会议纪要 Markdown 文件
- **HTML 导出**：生成可打印的 HTML 格式会议报告
- **JSON 导出**：导出结构化数据用于进一步处理
- **剪贴板复制**：一键复制会议纪要到剪贴板

### 3. 🎨 头像生成
- **用户头像**：基于姓名自动生成彩色头像
- **机器人头像**：SVG 绘制的可爱机器人头像
- 无需依赖外部图片资源

### 4. 📝 实时转写模拟
- **逐步显示**：会议记录逐条显示，模拟真实转写效果
- **可控进度**：支持暂停、继续、重置转写流
- **事件监听**：基于观察者模式的更新机制

### 5. ⚙️ 增强的用户体验
- **自定义时长**：支持输入任意会议时长（5-240 分钟）
- **文件验证**：上传文件时验证格式和大小（最大 10MB）
- **错误提示**：友好的错误信息和操作反馈
- **待办管理**：支持添加、编辑、删除待办事项
- **实时提醒**：会议临近结束时自动提醒

### 6. ♿ 无障碍改进
- **ARIA 标签**：为所有交互元素添加语义化标签
- **键盘导航**：支持完整的键盘操作
- **屏幕阅读器**：Toast 通知支持 aria-live

### 7. 🛠️ 工具函数库
- **验证工具**：会议名称、议程、文件格式验证
- **格式化工具**：时间、日期、文件大小格式化
- **性能优化**：防抖和节流函数

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173` 启动。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

## 🎯 功能页面

### 1. 会前准备（第 0 页）
- 设置会议名称、议程、时长
- 上传会议相关资料
- 查看最小配置总结

### 2. 会中主持（第 1 页）
- 实时显示会议目标和当前议题
- 逐步展示会议记录
- 音视频控制（静音、关闭视频、共享屏幕）
- 会议临近结束提醒

### 3. 会中助手（第 2 页）
- **会中助手**：向机器人提问并记录重点
- **会议记录**：查看完整的实时转写
- **待办事项**：管理会议待办（增删改查）
- **会议资料**：查看上传的文件列表

### 4. 会后确认与追踪（第 3 页）
- AI 生成的会议总结
- 关键结论列表
- 待办事项确认
- 多种格式导出
- 下次会议追踪

## 🔧 技术栈

- **React 19.2.0** - UI 框架
- **Vite 6.4.2** - 构建工具
- **Phosphor Icons** - 图标库
- **LocalStorage API** - 数据持久化
- **Clipboard API** - 剪贴板操作
