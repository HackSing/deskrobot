## 💡 使用流程演示

### 步骤 1：会前准备
1. 输入会议名称（如"产品周会"）
2. 填写会议目标/议程（支持多行）
3. 选择预计时长（或自定义输入）
4. 上传相关资料（可选，拖拽或点击）
5. 点击"开始这场会议"

### 步骤 2：会中主持
1. 查看实时计时器和进度条
2. 观察会议记录逐步生成
3. 切换议题进度
4. 使用音视频控制（模拟）
5. 点击"向会议提问"进入助手模式

### 步骤 3：会中助手
- **会中助手 Tab**：
  - 输入问题，AI 回答（关键词匹配）
  - 点击"记一下这个重点"标记重要内容
  
- **会议记录 Tab**：
  - 查看完整转写记录
  - 点击任意记录高亮显示
  
- **待办事项 Tab**：
  - 添加新待办（点击"+ 添加待办事项"）
  - 编辑任务内容、负责人、截止日期
  - 勾选完成状态
  - 删除不需要的待办
  - 筛选"全部/待办/已完成"
  
- **会议资料 Tab**：
  - 查看已上传的文件列表

### 步骤 4：结束会议
1. 点击"结束会议"按钮
2. 自动跳转到"会后确认与追踪"页面

### 步骤 5：会后总结
1. 查看 AI 生成的会议总结
2. 查看关键结论列表
3. 确认或编辑待办事项
4. 选择导出格式：
   - **Markdown**：适合 GitHub/Notion
   - **HTML**：可打印的网页格式
   - **JSON**：结构化数据
   - **复制到剪贴板**：快速分享
5. 点击"确认待办"标记已完成

## 💾 数据存储说明

### LocalStorage 存储内容
- 会议名称、议程、时长
- 上传的文件列表
- 会议进行秒数
- 所有待办事项
- 标记的重点
- 问答历史
- 确认状态

### 数据恢复
刷新页面时会提示：
```
检测到上次未完成的会议，是否继续？
```
- 点击"确定"：恢复到上次状态
- 点击"取消"：开始新会议

### 清除数据
在"会后总结"页面 → 右侧面板底部：
```
🗑️ 清除所有保存的数据
```

## 🐛 常见问题

### Q: 为什么会议记录不更新？
A: 确保已点击"开始这场会议"，记录每 3 秒自动增加。

### Q: 导出的文件在哪里？
A: 浏览器默认下载目录，文件名包含会议名称和日期。

### Q: 可以修改已有的待办吗？
A: 可以，直接点击内容、负责人或日期字段编辑。

### Q: 数据会丢失吗？
A: 使用 LocalStorage 保存，除非：
- 清除浏览器数据
- 手动点击"清除所有保存的数据"
- 切换浏览器或设备

### Q: AI 问答为什么不准确？
A: 当前为演示版本，使用简单的关键词匹配。真实版本需要接入 LLM API。
